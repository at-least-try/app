# MVP UI Wireflow

## Screen 1: Onboarding

- Choose life-admin domains (Documents, Taxes, Subscriptions, Medical Bills, Relationships)
- Choose reminder style (gentle, standard, strict)
- Start as anonymous user and continue

## Screen 2: Dashboard

Sections based on `DashboardPlanner` output:

- Overdue
- Due Soon
- Upcoming
- Later

Each card shows:

- Title
- Days until due
- Criticality badge
- Quick action (`Start Process`, `Snooze`, `Mark done`)

## Screen 3: Cycle Detail

- Timeline progress
- Required docs checklist
- Next due date + lead-time reminders
- Rule actions currently attached

## Screen 4: Policy Rules

- Rule list sorted by priority
- Create/edit trigger and action mapping
- Toggle enabled/disabled

## Screen 5: Settings + Sync

- Auth upgrade (anonymous → Google/email)
- Reminders and calendar sync
- Export/import profile settings
